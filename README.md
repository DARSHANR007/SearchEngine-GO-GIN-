# 🔍 SearchEngine-GO-GIN

A simple web-based search engine built using **Go** and the **Gin** framework. This project indexes `.txt` files and provides a basic search interface over HTTP.

---

## 📌 Features

- ✅ Load and index `.txt` files from a directory  
- 🔍 Search for words and phrases  
- 🚀 Lightweight and fast (in-memory index)  
- 🌐 HTTP server using Gin framework  

---

## 🛠️ Tech Stack

- **Go (Golang)**  
- **Gin** – For building the HTTP server  
- **Go Templates** – For rendering simple HTML pages
